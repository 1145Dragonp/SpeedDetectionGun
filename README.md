# Speed detection gun

**Speed detection gun** is a lightweight client-side mod for Minecraft that adds a functional **speed detection gun**. When held, it displays your current movement speed in the top-left corner of the screen. You can also track other entities, so you can measure how fast mobs, players, or other creatures are moving.

## Key Features

- **Real-time Speed Display:** Calculates your current speed from positional changes and shows it in **km/h**.
- **EMA Smoothing:** Stabilizes the speed readout so the numbers don’t jump around.
- **Peak Speed Tracking:** Records the highest speed reached while holding the item.
- **Auto-reset Peak:** The peak value automatically clears after a period of inactivity.
- **Entity Tracking:** Sneak and right-click an entity to track its speed. Sneak and right-click air to clear the current target.
- **Settings Menu:** Right-click while holding the gun to open the settings menu, or adjust options directly in the configuration page.
- **Instant HUD Feedback:** The HUD appears when you hold the gun and disappears when you put it away.
- **Lightweight & Dependency-free:** Does not modify vanilla mechanics or affect save files. Suitable for single-player, multiplayer, and servers.
